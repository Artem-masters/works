Тренажер командной строки Windows
Интерактивное десктопное приложение на Python (Tkinter) для изучения и проверки знаний базовых команд cmd.exe. Программа представляет собой 50 уроков с теорией и практическими заданиями, выполняемыми в виртуальном терминале.

📋 Описание
Тренажер имитирует работу командной строки Windows в безопасной песочнице (виртуальном диске C:\). Пользователю предлагается изучить теоретический материал, а затем выполнить практические задания. Проверка введенных команд происходит автоматически. Программа содержит систему баллов, подсказок и выставления итоговой оценки.

✨ Возможности
50 интерактивных уроков по базовым командам Windows (навигация, работа с файлами, сеть, система).
Виртуальная файловая система: все действия (создание, удаление, перемещение файлов) происходят в изолированной временной папке и не навредят вашему компьютеру.
Многошаговые задания: многие уроки состоят из нескольких последовательных команд.
Симуляция реального терминала: программа понимает синонимы команд (например, mkdir и md), ключи (/a, /s), переменные среды и операторы перенаправления (>).
Гибкая система оценивания: баллы начисляются в зависимости от сложности задания. За неверные попытки начисляется штраф, а за использование подсказок предусмотрен лимит.
Встроенная теория: перед началом теста доступен подробный справочник по всем изучаемым командам.

Python 3.6+

🚀 Установка и запуск
💡 Внимание! Данный проект является частью большого учебного репозитория works, который содержит материалы и программы по другим предметам. Чтобы не скачивать лишние файлы, мы настоятельно рекомендуем использовать «разреженное» клонирование (Sparse Checkout) — оно загрузит только папку с тренажером.

Склонируйте структуру репозитория без лишних файлов:

bash
git clone --filter=blob:none --sparse https://github.com/Artem-masters/works.git
cd works

Укажите, что вам нужна только папка с тренажером:
bash
git sparse-checkout set Kursy/Informatika

Перейдите в папку с программой:
bash
cd Kursy/Informatika
Запустите программу:

Вариант А (исходный код): запустите Python-файл:
bash
python trainer_windows.py
(Убедитесь, что имя файла совпадает с тем, как вы его сохранили, например trainer.py или WindowsTrainer.py)

Вариант Б (готовый установщик): если вы скачали папку целиком, просто запустите один из исполняемых файлов двойным кликом мыши (в зависимости от вашей ОС):

WindowsTerminalTrainerSetup.exe (для Windows)

LinuxTrainerSetup.exe (для Linux)

📖 Как проходить обучение
Изучите теорию. При запуске программы откроется справочник по всем командам. Ознакомьтесь с ним и нажмите кнопку «Перейти к тесту ➡».

Выполняйте задания. В левой части экрана отображается задание, а в правой — виртуальный терминал.

Ввод команд. Вводите команды в поле ввода и нажимайте Enter или кнопку «▶ Выполнить». Если задание многошаговое, вводите команды по одной.

Подсказки. Если вы ошиблись 3 раза, вам станет доступна кнопка «💡 Подсказка». Помните, что количество подсказок на весь тест ограничено (10 штук).

Переход дальше. После успешного выполнения задания (или после 5 ошибок) загорится кнопка «⏭ Следующий».

Сброс. Если вы запутались в файлах в виртуальной папке, нажмите «🔄 Сброс». Учебные файлы восстановятся, но счетчик ваших ошибок сохранится.

⚙️ Технические детали
Безопасность: все файлы создаются в системной временной папке (tempfile.mkdtemp), которая удаляется при закрытии программы.

Кроссплатформенность: благодаря эмуляции путей, программа корректно работает как на Windows, так и на Linux/macOS, скрывая реальные пути к временным папкам и отображая привычный C:\.

Защита ответов: эталонные ответы к заданиям хранятся в коде в зашифрованном виде (Base64 + XOR), чтобы предотвратить их простое чтение из исходников.
