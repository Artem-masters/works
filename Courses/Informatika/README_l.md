🐧 Тренажер командной строки Linux
Интерактивное десктопное приложение на Python (Tkinter) для изучения и проверки знаний базовых команд bash. Программа представляет собой набор уроков с теорией и практическими заданиями, выполняемыми в виртуальном терминале.

📋 Описание
Тренажер имитирует работу командной строки Linux в безопасной песочнице (виртуальной файловой системе с корнем / и домашней папкой ~). Пользователю предлагается изучить теоретический материал, а затем выполнить практические задания. Проверка введенных команд происходит автоматически. Программа содержит систему баллов, подсказок и выставления итоговой оценки.

✨ Возможности
Множество интерактивных уроков по базовым и продвинутым командам Linux (навигация, работа с файлами, права доступа, сеть, администрирование).
Виртуальная файловая система: все действия (создание, удаление, перемещение файлов, изменение прав) происходят в изолированной временной папке и не навредят вашему компьютеру.
Многошаговые задания: многие уроки состоят из нескольких последовательных команд.
Симуляция реального терминала: программа понимает синонимы команд, ключи, переменные окружения ($HOME), маски (*, ?), перенаправления (>, >>) и кавычки.
Гибкая система оценивания: баллы начисляются в зависимости от сложности задания. За неверные попытки начисляется штраф, а за использование подсказок предусмотрен лимит.
Встроенная теория: перед началом теста доступен подробный справочник по всем изучаемым командам.
Кроссплатформенность: благодаря встроенной эмуляции (pwd, grp) программа корректно работает как на Linux/macOS, так и на Windows.

🖥️ Требования
Python 3.6+

Стандартная библиотека (tkinter входит в поставку Python)

⚠️ Важно: модуль tkinter должен быть установлен. В некоторых дистрибутивах Linux его нужно устанавливать отдельно:

bash
sudo apt install python3-tk
🚀 Установка и запуск
💡 Внимание! Данный проект является частью большого учебного репозитория works, который содержит материалы и программы по другим предметам. Чтобы не скачивать лишние файлы, мы настоятельно рекомендуем использовать «разреженное» клонирование (Sparse Checkout) — оно загрузит только папку с тренажером.

Склонируйте структуру репозитория без лишних файлов:

bash
git clone --filter=blob:none --sparse https://github.com/Artem-masters/works.git
cd works
Укажите, что вам нужна только папка с тренажером:
(Замените путь на актуальный, где лежит файл Linux-тренажера)

bash
git sparse-checkout set Kursy/Informatika
Перейдите в папку с программой:

bash
cd Kursy/Informatika
Запустите программу:

Вариант А (исходный код): запустите Python-файл:

bash
python linux_trainer.py
(Убедитесь, что имя файла совпадает с тем, как вы его сохранили)

Вариант Б (готовый установщик): если вы скачали папку целиком, просто запустите один из исполняемых файлов двойным кликом мыши (в зависимости от вашей ОС):

LinuxTrainerSetup.exe (если вы работаете в Windows, несмотря на название, или это исполняемый файл для Linux)

WindowsTerminalTrainerSetup.exe (если применимо)

📖 Как проходить обучение
Изучите теорию. При запуске программы откроется справочник по всем командам. Ознакомьтесь с ним и нажмите кнопку «Перейти к тесту ➡».

Выполняйте задания. В левой части экрана отображается задание, а в правой — виртуальный терминал.

Ввод команд. Вводите команды в поле ввода и нажимайте Enter или кнопку «▶ Выполнить». Если задание многошаговое, вводите команды по одной.

Подсказки. Если вы ошиблись 3 раза, вам станет доступна кнопка «💡 Подсказка». Помните, что количество подсказок на весь тест ограничено (10 штук).

Переход дальше. После успешного выполнения задания (или после 5 ошибок) загорится кнопка «⏭ Следующий».

Сброс. Если вы запутались в файлах в виртуальной папке, нажмите «🔄 Сброс». Учебные файлы восстановятся, но счетчик ваших ошибок сохранится.

⚙️ Технические детали
Безопасность: все файлы создаются в системной временной папке (tempfile.mkdtemp), которая удаляется при закрытии программы. Тренажер не имеет доступа к вашей реальной файловой системе.

Кроссплатформенность: благодаря эмуляции путей, программа корректно работает как на Windows, так и на Linux/macOS, скрывая реальные пути к временным папкам и отображая привычный /home/user.

Защита ответов: эталонные ответы к заданиям хранятся в коде в зашифрованном виде (Base64 + XOR), чтобы предотвратить их простое чтение из исходников.

Эмуляция Linux в Windows: при запуске на Windows программа автоматически подменяет системные вызовы pwd и grp, чтобы команды id, whoami и другие работали корректно.
