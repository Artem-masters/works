Калькулятор выслуги лет (УИС)
Десктопное приложение на Python (Tkinter) для расчёта календарной и льготной выслуги лет с учётом коэффициентов для различных типов службы.

📋 Описание
Программа позволяет рассчитывать выслугу лет на основе введённых периодов службы/учёбы/отпусков. Для каждого периода указывается тип, дата начала и дата окончания. При расчёте учитывается повышающий коэффициент 1.5 для службы в уголовно-исполнительной системе (УИС), для остальных типов применяется коэффициент 1.0.

✨ Возможности
Добавление неограниченного количества периодов

Выбор типа периода из выпадающего списка:
Служба в УИС (коэффициент 1.5)
Армия
Вуз
Ведомственный вуз
Отпуск по уходу за ребенком
Правоохранительные органы
Автоматический пересчёт коэффициента при смене типа периода
Удаление отдельных периодов
Расчёт календарной выслуги (без учёта коэффициентов)
Расчёт льготной выслуги (с учётом коэффициентов)
Вывод результата в удобном формате: годы, месяцы, дни

🖥️ Требования
Python 3.6+

Стандартная библиотека (tkinter входит в поставку Python)

⚠️ Важно: модуль tkinter должен быть установлен. В некоторых дистрибутивах Linux его нужно устанавливать отдельно:

bash
sudo apt install python3-tk
🚀 Установка и запуск
Клонируйте репозиторий или скачайте его в виде ZIP-архива:

bash
git clone https://github.com/Artem-masters/works.git
cd works
Запустите программу (исходный код):

bash
python calculator.py
или

bash
python3 calculator.py
💡 Для пользователей Windows: В папке Программы также находится готовый скомпилированный файл UIS_calc.exe. Вы можете запустить его двойным кликом мыши без установки Python.
📖 Использование
Ввод дат — используйте формат ДД.ММ.ГГГГ (например, 01.01.2000).
Добавление периода — нажмите кнопку «➕ Добавить период», выберите тип и введите даты начала и окончания.
Удаление периода — нажмите красную кнопку «✕» напротив ненужной строки.
Расчёт — нажмите «Рассчитать». В нижнем поле появится результат:
Календарная выслуга по каждому периоду и суммарно
Льготная выслуга с учётом коэффициентов и суммарно

Пример вывода
text
=== Календарная выслуга ===

Служба в УИС: 5 лет 3 мес 12 дн
Армия: 2 года 0 мес 0 дн

Всего календарная: 7 лет 3 мес 12 дн

=== Льготная выслуга ===

Служба в УИС (коэф. 1.5): 7 лет 10 мес 18 дн
Армия (коэф. 1.0): 2 года 0 мес 0 дн

Всего льготная: 9 лет 10 мес 18 дн
⚙️ Как работает расчёт
Календарная выслуга — количество дней между датой начала и датой окончания периода.
Льготная выслуга — календарные дни × коэффициент (1.5 для службы в УИС, 1.0 для остальных типов).
Перевод дней в годы/месяцы/дни выполняется по усреднённым значениям:
1 год ≈ 365.25 дней
1 месяц ≈ 30.44 дней
